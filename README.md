Sistema de Gestao de Clientes

Projeto desenvolvido em Pytho utilizando Pandas para controle de clientes, servicos e faturamentos

Funcionalidades:
- Acessar banco de dados em Dataframe
- Visualizar primeiros registros
- Visualizar ultimos registros
- Calcular valor total
- Calcular valor medio
- Transforma e le o arquivo em Excel(.xlsx)

Tecnologias:
- Pythons
- Pandas
